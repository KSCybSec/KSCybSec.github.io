15 QUESTIONS BEGINNER LEVEL
QUESTION 01 / 15 7%
CLUE 001

A company wants to protect its computers and data from attacks. What field is this?

SCENARIO The company is reviewing its systems, networks and employees to reduce security risks.
CORRECT
Cybersecurity focuses on protecting systems, networks, devices and data from threats.
CLUE 002

Your computer needs to communicate with another device. What identifies the device on the network?

SCENARIO A technician asks for the device's network address so they can identify which machine they are connecting to.
CORRECT
An IP address identifies a device or network interface on an IP network.
CLUE 003

A scan shows port 80 is open on a server. What does that usually suggest?

SCENARIO You run a basic network scan and see TCP port 80 responding on a server.
CORRECT
Port 80 is commonly associated with HTTP, so an open port can indicate that a web service is listening there.
CLUE 004

You send important data using TCP. What is TCP designed to provide?

SCENARIO A file is being transferred and the sender needs reliable delivery rather than simply sending packets without checking them.
CORRECT
TCP uses mechanisms such as acknowledgements and sequencing to provide reliable, ordered communication.
CLUE 005

You type a website name instead of an IP address. What helps find its IP address?

SCENARIO Your browser needs to find the network address associated with a domain such as example.com.
CORRECT
DNS translates domain names into IP addresses that systems can use to communicate.
CLUE 006

A website uses HTTPS instead of HTTP. What does HTTPS add?

SCENARIO You are entering information into a website and notice the address begins with HTTPS.
CORRECT
HTTPS uses TLS to help protect data exchanged between the client and the server.
CLUE 007

A firewall sees an incoming connection that violates its rules. What can it do?

SCENARIO An organization's firewall receives a connection that is not allowed by its configured rules.
CORRECT
Firewalls control network traffic according to configured rules and policies.
CLUE 008

Files on a computer suddenly become encrypted and the attacker demands payment. What is this?

SCENARIO A user can no longer open their documents and sees a message demanding money to restore access.
CORRECT
Ransomware is malware that can encrypt or otherwise block access to data and demand payment.
CLUE 009

You receive an email pretending to be your bank and asking you to click a login link. What should you suspect?

SCENARIO The message creates urgency and asks you to enter your banking credentials through a provided link.
CORRECT
Phishing attempts to trick people into revealing information or taking an unsafe action.
CLUE 010

A website asks for your username and password. Which security concept is checking who you are?

SCENARIO You enter your credentials and the system checks whether they belong to your account.
CORRECT
Authentication answers: "Who are you?" Authorization answers: "What are you allowed to access?"
CLUE 011

A website stores passwords as hashes instead of plain text. Why?

SCENARIO A database is compromised. The attacker finds password hash values rather than a list of readable passwords.
CORRECT
Hashing provides a one-way transformation commonly used for storing password verifiers rather than plain passwords.
CLUE 012

A company wants to make sure its files have not been changed without permission. Which CIA principle applies?

SCENARIO An important report must remain unchanged unless an authorized employee modifies it.
CORRECT
Integrity means keeping information accurate and protected from unauthorized modification.
CLUE 013

Before attempting an attack, someone gathers information about a target. What stage is this?

SCENARIO An attacker looks for domains, IP addresses, technologies and publicly available information about an organization.
CORRECT
Reconnaissance is the information-gathering stage where a target is studied before further actions.
CLUE 014

A user successfully logs in but cannot open the administrator settings. What concept controls this?

SCENARIO The system knows who the user is, but the user does not have permission to access a particular resource.
CORRECT
Authorization determines what an authenticated user is allowed to access or do.
CLUE 015

Someone gathers information about a target, finds a way in, and then tries to access resources. What does this show?

SCENARIO The activity happens in stages rather than as one single action: information gathering comes before exploitation and access.
CORRECT
Real attacks can involve multiple stages, such as reconnaissance, initial access, exploitation and actions after gaining access.
