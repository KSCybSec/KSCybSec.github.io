What would you check first?

Before a device can communicate normally, it needs network configuration. You have just connected this laptop to the network.

Evidence found

✓

Connection traced.

You followed the request from the device toward the website.

01 · DHCP The device receives its network configuration.
02 · IP address The device gets an address such as 192.168.1.24.
03 · Default gateway Traffic leaving the local network goes through the gateway/router.
04 · DNS The domain name is resolved to an IP address.
05 · TCP / HTTPS The browser can then establish the connection to the web service.
