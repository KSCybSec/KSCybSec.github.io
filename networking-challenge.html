Networking Path · Investigation Challenge

Trace the
network.

You've learned how networks connect, how devices get addresses, how traffic moves, and how services reveal clues.

Now put those clues together.
You're investigating a small network. Nothing is broken. Nothing is obviously malicious. Your job is simply to understand what you're looking at.
01 · The situation

A laptop joined the network.

A laptop has just connected to a small office network. The network administrator gives you a few pieces of information and asks:

“Can you figure out what is on this network?”

NETWORK CONFIGURATION
Device: Laptop
IP Address: 192.168.1.24
Default Gateway: 192.168.1.1
DNS Server: 192.168.1.1
02 · First clue

The network responds.

A scan was performed on the local network. You don't need to run anything yourself. The results are already here.

SCAN RESULTS
192.168.1.1 → 80/tcp open
192.168.1.1 → 443/tcp open

192.168.1.20 → 22/tcp open
192.168.1.20 → 443/tcp open

192.168.1.30 → no response
CLUE 01

Which device is most likely acting as the laptop's gateway?

The laptop's configuration already identifies 192.168.1.1 as its default gateway.
CLUE 02

Which host clearly exposes a web service?

Port 443 is commonly associated with HTTPS, so 192.168.1.20 clearly exposes a web service.
03 · Local discovery

One address isn't enough.

The laptop knows that 192.168.1.20 exists. But local Ethernet or Wi-Fi communication also needs the destination network interface's hardware address.

ARP CACHE
192.168.1.1 → 8A:31:44:72:10:01
192.168.1.20 → 3C:52:82:7A:91:4F
CLUE 03

What does 3C:52:82:7A:91:4F represent here?

The colon-separated hexadecimal value is a MAC address, which identifies a network interface on the local network.
CLUE 04

The laptop knows 192.168.1.20 but needs its MAC address. Which protocol helps with this on an IPv4 local network?

ARP resolves an IPv4 address to a MAC address on the local network.
04 · Put the clues together

What is that machine?

You now know that 192.168.1.20 has two open ports: SSH on port 22 and HTTPS on port 443.

You also know its MAC address from the ARP cache. You don't need to guess an exact device model. You're looking for its most reasonable role.

CLUE 05

Based on the available evidence, what is the most likely role of 192.168.1.20?

The host exposes both HTTPS and SSH, which are commonly provided by servers or other networked systems offering services. The evidence does not justify a more specific device identification.
FINAL CLUE

You want to discover more hosts, ports and services on an authorized network. Which tool would naturally be useful?

Nmap is a network discovery and scanning tool commonly used to identify hosts, ports and services on authorized networks.
