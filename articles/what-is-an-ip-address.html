Beginner Path · 003

What Is an IP Address?

Your request has to reach somewhere. But how does your computer know where to send it?

Let's go back to where we left off.

You opened your browser, typed a website address, and pressed Enter.

Your computer had to find the right destination before it could send the request.

We talked about DNS helping turn a name like example.com into something a computer can use.

But that leaves us with another question.

Pause for a second

If computers need addresses to communicate, what exactly does that address look like?

Imagine sending a letter

Suppose you want to send a letter to a friend.

Writing your friend's name on the envelope isn't enough. The postal system needs an address.

The address tells the system where the letter needs to go.

Computers need something similar.

When one device wants to communicate with another device over a network, it needs a way to identify the destination.

That's where an IP address comes in.

An IP address is a numerical address used to identify a device or network interface so that data can be sent to the right destination.

So what does one look like?

You've probably seen something like this before:

EXAMPLE DEVICE
192.168.1.25
An example IPv4 address

At first glance, it looks like four numbers separated by dots.

That's an example of an IPv4 address, one of the most common forms of IP addressing you'll encounter while learning networking and cybersecurity.

Each number can range from 0 to 255, giving IPv4 its familiar format.

You don't need to memorize the mathematics behind it yet. What's more important is understanding the idea:

Devices communicating on a network need addresses so that traffic has somewhere to go.

But here's something interesting

Look again at this address:

192.168.1.25

You might have seen addresses beginning with 192.168 on your own computer or phone.

That's because addresses such as these are commonly used inside private networks.

Your home might have several devices connected to the same router:

Laptop → Phone → Smart TV → Router

They can each have their own private IP address inside your local network.

Your router then helps that local network communicate with the wider Internet.

Wait — then what is a public IP?

Here's where the picture gets a little bigger.

Your laptop can have a private address inside your home network, while your network itself communicates with the Internet through a public IP address.

You can think of it like an apartment building.

Inside the building, individual apartments have their own numbers. From the outside, however, the building has one street address.

A private IP helps identify something inside the local network. A public IP can identify the network's connection to the wider Internet.

The comparison isn't perfect, but it gives you the basic idea.

And this is where the router matters

Remember the request we were following in the previous article?

Your computer doesn't simply throw data onto the Internet and hope someone finds it.

Your router sits between your local network and the wider network.

Your Device → Router → Internet → Destination

It helps determine where traffic should go and where returning traffic should come back.

That's one reason networking becomes so important in cybersecurity.

When you're investigating suspicious activity, you often need to understand where traffic came from, where it was going, and what devices were communicating.

An IP address isn't a person's identity

There's an important detail worth remembering.

Seeing an IP address does not automatically tell you who a person is.

An address might belong to a home network, an organisation, a mobile provider, a cloud server, a VPN service, or many other kinds of infrastructure.

Multiple people can appear to use the same public IP address. Addresses can change. Devices can move between networks.

So if a security log says:

“Connection received from 203.0.113.25.”

that's a clue — not a complete story.

A security analyst would normally need more evidence to understand what actually happened.

Now think like a security analyst

Imagine you're looking at a security alert.

It says that a server received several unexpected connections from the same IP address.

Is that automatically an attack?

Not necessarily.

Maybe it's a legitimate service. Maybe it's a vulnerability scanner. Maybe it's an employee's network. Maybe it's something genuinely suspicious.

The IP address gives you a place to start investigating. It doesn't give you the entire answer.

Think like an investigator

What else would you want to know before deciding what those connections actually mean?

This is a useful cybersecurity habit: don't treat one piece of information as the whole story.

There's still something missing

So far, we've answered one important question.

We know how a device can have an address.

We know that address helps traffic reach the right destination.

But there's a problem.

Imagine a huge office building.

You know the building's address.

But that's not enough to find a particular room inside it.

The same idea appears in networking.

An IP address can help identify the destination machine or network. But once traffic reaches that machine, something else helps determine which service should receive it.

That's where our next clue appears.

Remember this

An IP address helps identify where network traffic should go — but an address alone doesn't tell you the whole story.
