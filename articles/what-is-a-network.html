What Is a Network?

Before we start scanning networks, tracing traffic, or investigating suspicious connections, we need to understand one simple thing: how devices talk to each other.

NETWORKING · ~5 MIN READ · CLUE 016

You open your laptop.

Your phone is connected to Wi-Fi. A printer is sitting somewhere in the room. You open a website and, within seconds, the page appears.

None of these devices are sitting inside the same computer. Yet somehow, they communicate.

So how do they find each other?

This is the basic idea behind a network.

A network is simply a group of devices that can communicate with each other.

It could be three devices connected to the same Wi-Fi router. It could be hundreds of computers inside a company. Or it could be millions of devices communicating across the Internet.

The size changes. The basic idea doesn't.

But connecting a few devices isn't enough

Imagine walking into a room where ten people are talking at once.

You want to send a message to one particular person. If you don't know who they are, where they are, or how they expect to receive the message, things get messy very quickly.

Networks have the same problem.

Devices need ways to identify each other. They need ways to send information. And they need agreed rules for how that information should travel.

The information doesn't magically jump from your laptop to the website's server.

It travels through a network.

Along the way, different networking technologies help decide who should receive the data, where it should go, and how it should get there.

STOP & THINK

If two devices are connected, how does one know which device it should talk to?

That's where addresses come in

You've already met one kind of network address in the previous path: the IP address.

An IP address helps identify a device on a network and gives networking equipment information about where traffic should go.

But IP isn't the only kind of address you'll encounter.

Devices also have MAC addresses, which are tied to their network interfaces and are especially important when communicating inside a local network.

Don't worry about memorizing all of that yet.

We're going to follow those clues one at a time.

Not every network looks the same

The Wi-Fi network in your home is a network.

A university computer lab can be a network.

A company's internal infrastructure can contain many connected networks.

And the Internet connects networks across the world.

That's why you'll soon hear terms such as LAN, WAN, router, subnet, NAT and more.

They aren't random vocabulary. Each one describes a different piece of the communication puzzle.

Why should a security learner care?

Because communication creates clues.

When devices communicate, there are addresses. There are connections. There are services. There are requests and responses.

And when something unusual happens, those clues can become extremely useful.

A security analyst might ask:

Which device made this connection? Where did it connect? Which service was involved? Was that communication expected?

Before we can investigate those questions, we need to understand the network underneath them.
