NAT: How Private Networks Reach the Internet

Your laptop has a private IP address. The website is somewhere on the public Internet. So how does that private address actually communicate with the outside world?

NETWORKING BEGINNER ~5 MIN READ

Look at the IP address of a device on a typical home network.

It might be something like 192.168.1.24.

Your phone might have another private address. Your laptop has another. Your smart TV has another.

Yet all of them can open websites on the Internet.

There is a clue sitting at the edge of your network: NAT.

The problem with private addresses

IPv4 addresses are limited. There are only about 4.3 billion possible IPv4 addresses, and the world has far more devices than that.

To make large numbers of devices possible, networks commonly use private IPv4 address ranges.

COMMON PRIVATE IPv4 RANGES
10.0.0.0/8
10.0.0.0 – 10.255.255.255
172.16.0.0/12
172.16.0.0 – 172.31.255.255
192.168.0.0/16
192.168.0.0 – 192.168.255.255

These addresses are intended for use inside private networks. They are not globally unique Internet addresses.

Enter NAT

NAT stands for Network Address Translation.

NAT allows a network device, commonly a router or firewall, to translate between private and public IP addressing.

That means many devices inside a private network can communicate with the Internet through a public-facing address.

From the perspective of the outside network, the traffic can appear to come from the public-facing address rather than the laptop's private address.

It's not just the IP address

There is another important detail.

A home network can contain several devices that all need to access the Internet at the same time.

So NAT commonly works together with port information to keep different connections separate.

SIMPLIFIED TRANSLATION VIEW
192.168.1.24 : 51520
203.0.113.10 : 40001
192.168.1.25 : 51521
203.0.113.10 : 40002
192.168.1.30 : 51522
203.0.113.10 : 40003

The exact implementation depends on the NAT method and device, but the basic idea is that the translation process keeps track of different connections.

When the reply comes back

The story doesn't end when the request leaves.

The website sends a response back toward the public address.

Website
→
Public IP
→
NAT
→
Laptop

The NAT device uses the information it kept about the connection to determine which internal device should receive the returning traffic.

That's how a single public-facing network connection can support communication from many private devices.

NAT is not the same as a firewall

These two concepts are often mentioned together, but they are not the same thing.

NAT is primarily about address and connection translation. A firewall is designed to enforce traffic rules and decide what should be allowed or blocked.

A router can perform NAT and also contain firewall functionality, which is why the two can appear together in a typical home network.

NAT may also make some unsolicited inbound connections more difficult, depending on the configuration, but it should not be treated as a replacement for proper firewall controls.

A device gets network information. It determines whether a destination is local or remote. A router provides the path between networks. NAT can translate private addressing for Internet communication.

But the Internet is not just a collection of IP addresses. Behind those addresses are services — websites, mail servers, DNS servers, remote-access services, and many others.

TAKEAWAY · 023

NAT translates network addressing so devices using private IPv4 addresses can communicate through a public-facing address. It commonly works with connection and port information to keep multiple internal connections separate. NAT and firewalls are related in many network devices, but they serve different primary purposes.
