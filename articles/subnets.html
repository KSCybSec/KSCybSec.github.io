Subnets: Dividing a Network

A network can contain hundreds or thousands of devices. How do we divide that huge space into smaller, understandable pieces?

NETWORKING BEGINNER ~5 MIN READ

Imagine a college network with 2,000 devices.

Students are using laptops. Staff have their own computers. Servers are running in another part of the building. Security cameras are connected too.

Putting every device into one giant network would make the environment difficult to organize.

So instead of treating the network as one enormous space, we divide it into smaller ones.

What is a subnet?

A subnet, short for subnetted network, is a smaller logical network created from a larger IP network.

Subnetting allows network administrators to divide addresses into manageable groups.

Think of it like a large building. The building is the network. Different rooms or departments are the subnets.

The clue inside an IP address

Earlier, we saw addresses such as:

EXAMPLE · IPv4 ADDRESS
IP ADDRESS
192.168.1.24
SUBNET MASK
255.255.255.0

The subnet mask helps a device determine which part of an IP address represents the network and which part represents the individual device.

You don't need to become a binary expert yet. The important idea is that the address contains information about where the device belongs.

A simple example

Consider this network:

192.168.1.0/24
→
256 total addresses

A `/24` network is a common notation used to describe the size of an IPv4 network.

In the familiar private IPv4 range above, the usable host addresses are commonly:

192.168.1.1
…
192.168.1.254

The `.0` address identifies the network itself, while `.255` is the broadcast address for this traditional `/24` IPv4 subnet.

So this gives us 254 commonly usable host addresses.

Why divide it?

Imagine putting students, staff, servers, and security cameras into one giant broadcast domain.

It may work technically, but it becomes harder to manage and control.

Subnets allow networks to be organized according to purpose.

EXAMPLE · DEPARTMENTAL NETWORKS
STUDENTS
STAFF
SERVERS

A network can therefore be designed so that different groups of devices live in different IP ranges.

Subnets and security

Subnetting is also useful from a security perspective.

Separating devices into different network segments can make it easier to control which systems are allowed to communicate with each other.

For example, an organization might place public-facing servers, employee devices, and sensitive internal systems into different network segments and then use routing or firewall rules to control traffic between them.

A subnet does not automatically make a network secure. It simply gives administrators a structure that can be used to apply security controls.

PAUSE FOR A SECOND

If a large network is divided into smaller IP networks, what might become easier to manage: the devices, the traffic, or both?

DHCP can give a device an IP address. The subnet tells the device which network that address belongs to.

And if the device needs to communicate with another device on that local network, ARP can help it discover the destination's MAC address.

But what happens when the destination is not on the local network?

That's when another important network device becomes part of the story: the router.

TAKEAWAY · 021

Subnets divide a larger IP network into smaller logical networks. They help organize devices, control network boundaries, and make large environments easier to manage. A subnet mask or prefix such as /24 helps define which addresses belong to the network.
