What Is OSINT?

Let's investigate a username and learn Open Source Intelligence along the way.

🧪 Training case

Everything in this investigation is fictional. We're using the username shadowfox23 only to learn the investigation process.

Let's investigate.

I'm going to give you one piece of information. 

shadowfox23

No name.

No email.

No profile link.

Your first question isn't:

“Who is this person?”

That's jumping way too far ahead.

Let's start with something much simpler:

“Where does this username appear?”

And while we try to answer that question, you'll learn what OSINT actually is.

First: what exactly is OSINT?

OSINT stands for Open Source Intelligence.

The name sounds more complicated than it really is.

Think about all the information people and organisations make publicly available:

  • Websites
  • Public social-media profiles
  • News articles
  • Public documents
  • Domain information
  • Public repositories
  • Images
  • Forum posts
  • Technical information

An investigator can collect information from these sources, compare it, verify it, and use it to answer a specific question.

That's the important part.

OSINT isn't simply “Googling something.”

It's about turning publicly available information into something useful and supported by evidence.

Now let's see what that looks like.

Step 1 — Search

Our starting point is: 

shadowfox23

What would you do first?

You could immediately start opening ten different websites. But let's slow down.

A good investigation starts with a question.

Ours is:

“Where does shadowfox23 appear publicly?”

That's specific.

And because our question is specific, our search can be specific too.

Let's start with: 

"shadowfox23"

Why the quotation marks?

Because we're asking the search engine to look for that exact phrase.

Maybe we find:

  • GitHub
  • Reddit
  • A forum
  • An old blog post

Interesting.

But don't get excited yet.

We've found mentions, not an identity.

🧠 A useful OSINT habit

Whenever you find something interesting, ask yourself:

“What exactly did I find?”

Not:

“What do I think this means?”

For example, suppose you find: 

Username: shadowfox23
Platform: GitHub

What do you actually know?

You know that a GitHub account publicly uses that username.

You don't yet know who operates the account.

This sounds like a small distinction.

It's actually one of the most important habits in OSINT.

Step 2 — Look for connections

Let's search again: 

"shadowfox23" reddit

Suppose we find a Reddit account with the same username. 

GitHub  →  shadowfox23
Reddit  →  shadowfox23

So... same person?

Maybe.

But maybe is the keyword.

Two people can use the same username.

So instead of declaring a conclusion, we have another question:

“Is there evidence connecting these two accounts?”

That's how an investigation develops.

One answer creates another question.

Let's say we find another clue.

Imagine the GitHub profile contains a public website: 

https://example.com

And that website uses: 

shadowfox23

Now our picture looks like this: 

             shadowfox23
                  │
          ┌───────┼───────┐
          ↓       ↓       ↓
       GitHub   Reddit   Website

That's more interesting.

Why?

Because we aren't relying on one isolated clue anymore. We have multiple public sources that appear to be connected.

But we're still not done.

Step 3 — Verify

Imagine someone tells you:

“I found the same username on three websites. It's definitely the same person.”

Would you agree?

No.

Why?

Usernames aren't unique identifiers.

Someone else could have copied the username. Someone could have created a similar account. One account could be abandoned. The information could even be outdated.

So we need another step.

This is where OSINT becomes more than just searching.

Look for independent clues.

Let's say the GitHub profile links to the website. That's useful.

Now imagine the website also links back to the GitHub profile. That's a stronger connection.

Maybe both public profiles use the same unique profile image.

That's another clue.

Maybe both publicly mention the same project.

Another clue.

We're building independent pieces of evidence.

Think of it like a puzzle.

One piece doesn't tell you much. Several pieces that actually fit together tell you much more.

🧠 Quick challenge

Imagine you find:

Account A 

Username: shadowfox23
Platform: GitHub
Location: Chennai

Account B 

Username: shadowfox23
Platform: Reddit
Location: Chennai

Account C 

Username: shadowfox23
Platform: Personal website
Links to Account A

Which statement is safest?

A. All three accounts definitely belong to the same person.

B. There are multiple clues suggesting the accounts may be connected, but further verification is needed.

C. The Chennai location proves the accounts belong to the same person.

Answer: B.

Why?

Because OSINT is about evidence, not confidence.

Step 4 — Take notes

Here's something beginners often skip.

Take notes.

Seriously.

Once an investigation gets bigger, trying to remember everything in your head becomes painful.

A simple table is enough.

Finding Source Confidence
shadowfox23 appears on GitHub GitHub Confirmed
Same username appears on Reddit Reddit Confirmed
GitHub links to website GitHub Confirmed
Website uses same username Website Confirmed
Reddit belongs to same person — Not proven

Notice that last line.

We're not pretending to know something we haven't established.

That's good OSINT practice.

So where do the tools come in?

You might be thinking:

“Okay, but what tools do OSINT investigators actually use?”

There are plenty.

But don't make the classic beginner mistake of collecting 50 tools before learning what they're for.

Start with the question.

Then choose the tool.

🔎 Search engines

Useful for discovering publicly indexed information.

Examples include Google and Bing.

Search engines are often the first step in an investigation.

🌐 Domain investigation

Suppose our investigation leads us to: 

example.com

We might investigate the domain.

Questions could include:

  • When was it registered?
  • What name servers does it use?
  • What DNS records exist?
  • Has the domain changed over time?
  • Is it associated with other infrastructure?

This is where WHOIS and DNS lookup tools become useful.

🖼️ Image investigation

Suppose the account uses a profile picture.

Instead of simply looking at the image, we can ask:

“Where else has this image appeared?”

Reverse-image-search tools can help answer that.

Maybe it's the original image. Maybe it's been reposted. Maybe it's a stock photograph. Maybe it's completely unrelated.

Again:

Investigate. Don't assume.

🦠 Security intelligence

Now imagine the investigation involves a suspicious domain or IP address.

This is where platforms such as VirusTotal can become useful.

You might investigate whether an indicator has been observed in security-related datasets.

For a future SOC investigation, this type of information can become particularly useful.

Notice what we've actually done

We started with: 

shadowfox23

And gradually built:

Username Search results Possible accounts Possible connections Additional evidence Verification

That's an OSINT investigation.

Not because we used some magical tool.

Because we followed a method.

🚨 One rule I want you to remember

Here's probably the most useful sentence in this entire guide:

Finding information is not the same as proving something.

You might find:

  • The same username
  • The same image
  • The same location
  • The same website
  • The same writing style

Those can all be useful clues.

But each one needs context.

Good investigators don't ask only:

“Can I find it?”

They also ask:

“How reliable is it?”

And:

“What else would I need to verify it?”

That's the mindset you want to develop.

⚖️ A responsible approach

OSINT deals with publicly available information, but that doesn't mean everything is fair game for everything.

When you're learning, keep your investigations safe and authorised.

Good practice targets include:

  • Your own accounts
  • Fictional identities
  • Test usernames
  • Public organisations
  • Public websites
  • Authorised security investigations
  • CTF and training environments

And be careful with personal information.

The goal isn't to dig into someone's private life.

The goal is to learn how to research, connect and verify information responsibly.

📌 Your OSINT mental model

If you remember only one workflow from this guide, remember this:

Ask Search Collect Connect Verify Report

And every time you discover something, ask:

“What do I actually know?”

That question will keep you from turning a clue into a conclusion.

🎯 So... what is OSINT?

Now we can finally give the textbook definition.

OSINT, or Open Source Intelligence, is the process of collecting, evaluating, connecting and analysing information from publicly available sources to answer a specific question or intelligence requirement.

But honestly, I'd rather you remember this:

OSINT is the process of turning scattered public information into useful, verified understanding.

You start with a question.

You find clues.

You connect them.

You verify them.

And eventually, those scattered pieces begin to tell you something meaningful.

That's the interesting part.
