MAC Addresses

Your device has an IP address. But inside a local network, there's another address hiding underneath the communication. Let's find it.

NETWORKING · ~5 MIN READ · CLUE 018

Your laptop is connected to Wi-Fi.

Your phone is connected too.

Both devices have IP addresses.

Now imagine your laptop wants to send something to your phone.

It knows the phone's IP address.

But there's another question hiding underneath:

Which network interface should actually receive this data?

One device, more than one identity
DEVICE
Laptop
IP · 192.168.1.10
→
NETWORK INTERFACE
Wi-Fi Adapter
MAC · 3C:52:82:7A:91:4F

This is where the MAC address enters the story.

MAC stands for Media Access Control.

A MAC address identifies a network interface at the data-link layer of networking.

In simpler words: it helps devices communicate with each other on the same local network.

What does a MAC address look like?

Unlike an IP address such as 192.168.1.10, a MAC address usually looks like a sequence of hexadecimal values.

Example MAC address
3C:52:82:7A:91:4F six hexadecimal pairs

You might see MAC addresses written with colons, hyphens, or sometimes without separators depending on the operating system or tool displaying them.

The exact address is not something you need to memorize.

What matters is recognizing what it represents: a network interface.

Wait — why "network interface"?

Because your laptop doesn't magically connect to a network.

It uses a network interface.

For example, your laptop might have a Wi-Fi adapter. It might also have an Ethernet port.

Each interface can have its own MAC address.

So when someone says, "What's the MAC address of this computer?", the more precise question is really:

A BETTER QUESTION

"What's the MAC address of the network interface I'm talking about?"

Now let's put it back on the network

Imagine four devices connected to the same local network.

When devices communicate locally, network equipment needs to know where the data should be delivered.

Devices on one local network
Local Network FORWARDING TRAFFIC
💻 Laptop MAC A
📱 Phone MAC B
🖨 Printer MAC C
💻 Desktop MAC D

Each interface has its own MAC address.

That gives local networking equipment something concrete to work with when delivering Ethernet frames.

So is MAC the same as IP?

No.

They are both addresses, but they serve different purposes and operate at different layers of networking.

MAC ADDRESS
Identifies a network interface at the data-link layer and is used for local network communication.
IP ADDRESS
Provides a logical address used by the network layer to identify and route traffic between networks.

Here's an easy way to think about it.

An IP address helps describe where a device is on a network.

A MAC address identifies the network interface involved in local communication.

That's simplified, but it's enough for where we are right now.

STOP & THINK

If a laptop knows another device's IP address, how can it discover the MAC address it needs for local delivery?

That's our next clue

We now have a small mystery.

A device knows an IP address.

But local communication also needs a MAC address.

Something has to connect those two pieces of information.

On an IPv4 local network, that job is handled by ARP — Address Resolution Protocol.

We'll follow that conversation in the next article.

Why should you care about MAC addresses?

Because network investigations often start with small details.

An analyst might see a MAC address in network information, DHCP records, switch data, wireless logs, or other troubleshooting and monitoring information.

By itself, a MAC address doesn't tell you everything about a device.

But when combined with other clues, it can help connect network activity to a particular interface or device.

Go back to the laptop and phone from the beginning.

The laptop wants to talk to the phone.

It knows where the phone is logically. But local delivery needs another piece of information.

Somewhere inside that simple Wi-Fi conversation, the network needs to answer a very ordinary question:

"Which interface belongs to that address?"

And that's where our next clue begins.

TAKEAWAY
A MAC address identifies a network interface and plays an important role in communication on a local network. IP and MAC addresses are different pieces of the networking puzzle.
