What Is a Firewall?

Your computer is constantly talking to other systems. A firewall helps decide which conversations are allowed to continue.

Your laptop is connected to the Internet.

Your browser is loading a website. Your email app is checking messages. Something else might be downloading an update.

All of that means one thing: network traffic is moving.

Think about it

What would happen if your computer simply accepted every connection that came its way?

Probably not something you'd want.

Before the firewall
Internet many connections
→
Your system services

Somewhere between the outside world and the system we want to protect, we need a way to control that traffic.

That's where the firewall comes in.

A checkpoint for network traffic

With a firewall
Internet incoming traffic
→
FIREWALL check the rules
→
System protected network

Think of a firewall like a security checkpoint.

Traffic arrives. The firewall checks it against its rules. Then it decides what happens next.

Allow or block?

TRAFFIC Connection attempt
FIREWALL
DECISION Allow / Block

The important part is that the firewall isn't simply guessing.

It uses rules.

Rules give the firewall its instructions

A rule might look at things such as an IP address, port, protocol, or connection state.

TCP/443 HTTPS traffic ALLOW
TCP/22 SSH BLOCK
UDP/53 DNS ALLOW

These are just simplified examples. Real firewall rules can be much more detailed.

Now let's investigate a real situation

Imagine you're looking at a server.

You notice repeated connection attempts arriving at a port that shouldn't normally be exposed.

You check the firewall.

The attempts were blocked.

The attacker didn't necessarily get in. But the traffic itself became a clue.

This is where cybersecurity becomes interesting.

A firewall doesn't just help control access. Its logs can also help security teams understand what is happening around a system.

But a firewall isn't a magic shield

Suppose someone sends you a convincing phishing email.

The firewall isn't necessarily going to recognize the email as a scam.

That's because different security controls solve different problems.

Firewall → controls network traffic
Authentication → protects access
Encryption → protects information
Monitoring → helps detect suspicious activity

Cybersecurity works through layers, not one magical defense.

Look how far we've come

Earlier, we followed a website request from a domain name all the way to a service.

Now we can add another piece to that journey.

Domain → DNS → IP → Port → TCP / UDP → Firewall → Service

Each piece answers a different question.

And the more pieces you understand, the easier it becomes to investigate what is actually happening on a network.

Remember this

A firewall uses rules to control network traffic, deciding what should be allowed to reach a system or network and what should be blocked.
